# Demo Script

1. Open the frontend at `http://localhost:5176`.
2. Show the learner dashboard for `COURSE-DEMO` and `STU-001`.
3. Run `python scripts/demo_pipeline.py` to complete a lesson.
4. Refresh the dashboard and show updated progress and points.
5. Submit a quiz through the gateway or direct service.
6. Show webinar records and YouTube publish integration.
7. Open `docs/project_report.md` and summarize delivered metrics.
